# Explorateur carburants dans une page

## Objectif et hypothèse
Tester l’explorateur carburants intégré dans une page data.gouv.fr, avec une introduction, un mode plein écran et des informations sur les données.

## État
Fonctionnel : réutilise le même composant et les mêmes données fictives que l’exploration autonome. Carte, recherche, filtres et fiches station sont partagés.

## Inspirations
Explorateur DVF dans une page et conventions visuelles data.gouv.fr.
