# Explorateur DVF

Reconstruction haute fidélité de l’application publique d’exploration des demandes de valeurs foncières.

## Objectif

- disposer d’une référence fidèle de l’interface existante ;
- simuler les données cartographiques et les résultats ;
- itérer ensuite sur les composants et les parcours sans modifier le traitement métier réel ;
- produire un support testable et transmissible à l’équipe de développement.
