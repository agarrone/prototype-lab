# Explore in a page

## Objectif

Tester l’intégration d’un bloc explorateur de données dans une page éditoriale de type article.

## Hypothèse testée

Permettre au lecteur d’explorer les données au fil du contenu facilite leur compréhension sans imposer une navigation vers une page dataset dédiée.

## État d’avancement

Première version du prototype. La page reprend l’explorateur utilisé dans `Explore in context` et l’intègre dans un gabarit éditorial inspiré de FR Content.

## Inspirations

- Pages éditoriales du système de design de l’État
- Prototype `Explore in context`
- Pages de guides et de ressources de data.gouv.fr
