# Activités

## Objectif

Améliorer la lisibilité de l'historique des modifications d'un jeu de données dans son espace d'administration.

## Hypothèse testée

Le regroupement des actions rapprochées par acteur permet de comprendre plus rapidement qui a modifié quoi et quand, sans alourdir la page.

## État d'avancement

Prototype haute fidélité. Les activités sont regroupées par mois et les séquences comportant plusieurs actions affichent directement leur détail et leur plage horaire.

Deux jeux de données sont proposés : un scénario fictif couvrant les principaux cas d’usage et un exemple concret fondé sur le flux public d’activités de Base Sirene. Le second ne conserve que les événements qui modifient le jeu de données ou ses ressources.

## Inspirations

Interface d'administration data.gouv.fr fournie sous forme de capture d'écran et conventions visuelles DSFR.
